What happens when you type google.com in your browser and press Enter

This project explains what happens behind the scenes when a user types a website URL in the browser.

It covers the full flow from the browser to the server and back.

Topics included:
- DNS request
- TCP/IP connection
- Firewall
- HTTPS / SSL (encryption)
- Load balancer
- Web server
- Application server
- Database

Files:

0-blog_post
Contains the link to my blog post.

1-what_happen_when_diagram
Contains the link to the diagram that shows the request flow.

Goal:
To understand how the web works step by step in a simple way.
